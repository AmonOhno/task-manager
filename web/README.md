# Task Manager (Demo)

This is a minimal browser demo implementing the TODO list requirements from `docs/Arc-UI_TodoList.md`.

Quick start:

1. cd web
2. npm install
3. npm run dev

Features included:

- React + TypeScript + Vite
- Tailwind CSS
- Zustand store with sample data
- TODO一覧: 並び順（期限超過→今日→明日→その他）、期日フォーマット、完了ボタン、工数ログ(+30m)、キャパシティ表示

Next steps:

- Persistent backend API
